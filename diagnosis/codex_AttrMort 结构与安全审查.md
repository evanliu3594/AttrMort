## 🔐 安全发现

### S1．P2／中等严重性：外部端点在错误消息中被求值

根因位置为 R/mortality.R：855–860，实际解释入口为 R/AttrMort-package.R：50–51。

读取 CSV／Excel 或 data.frame 后，端点仅做字符转换和小写化。没有共同端点时，端点列表被直接拼进 .abort 的消息正文。cli_abort 对该字符串先做 format_inline，再抛出错误，因此诊断文字中的花括号成为表达式。

最小无副作用探针把 mortality 的端点设为 `{1+1}`，实际报错显示 `mort_rate values: 2`，不是字面标签。安装的 cli 3.6.6 函数体也确认先执行 format_inline。未运行文件、网络、子进程或其他有副作用的表达式。

用户只授权读取数据，数据提供者却能影响调用者进程中的表达式执行。这是 CWE-94，不是普通报错文本缺陷。需要用户导入第三方数据并触发端点不匹配；没有远程服务证据，因此按中等严重性校准。命名模型的 validate＝stop 可以提前阻断全端点不匹配，但默认 warn、off，以及直接自定义 CRF 并未全面阻断。

同一控制缺失还出现在 R/mortality.R：977–983 的 age_txt 空连接报错，直接 CRF data.frame 可控制该年龄文本。JSON 年龄已经数值化，不能据此声称 JSON 年龄也有任意文本注入。

建议让模板保持固定，将端点列表、模型名和 age_txt 先赋给局部字符串，再作为值替换。R/ingest.R：110–116 的 mapping_txt 是已有安全对照。不能直接全局关闭 .abort 的插值，否则会破坏现有合法占位符。

### S2．P3／低严重性：紧凑年龄配置可触发无界资源展开

根因位置为 R/cr-config.R：54–62。

外部 JSON 的 from、to、by 仅检查数值、顺序、步长和整除关系，未检查有限性或基数，然后调用 seq 并转换为字符。安全的小范围探针接受 0 到 10000 的范围并生成 10001 个年龄；没有运行耗尽内存的输入。

静态证据支持小文件引发巨大序列分配；本地风险为用户 R 会话可用性，不是远程拒绝服务或主机接管。需要主动导入第三方配置。R 的字符转换可能延迟，但数值序列已经分配；后续查表展开还会消费年龄集合。建议在 seq 之前计算基数并设置明确上限。上限是多少属于公共契约，应由维护者决定，不能由审查直接改口径。

未报告的安全猜测包括：显式输出路径的越目录行为、配置支持绝对路径、开发脚本加载自身 rda、VRT 的二级资源引用。这些分别是调用者授权行为或缺少依赖实现证据，不构成本次已验证漏洞。

## ⚠️ 计算与契约缺陷

以下优先级用于修复排程，不代表网络安全严重性。除静默模式外，这些问题会影响结果或输入对齐，属于对应场景的阻断项。

### C1．P1：人口细化把每格总量当成连续强度

位置：R/raster-io.R：108–111。

目标网格更细时调用 bilinear。单个 2×2 度人口格存有 100 人，细化成四个 1×1 度格后，总量变成 400 人，偏差 300％。代码随后告警，但仍返回错误人口。

这不是“重采样必然损失”的固有缺口：pop 契约是人数，应守恒。测试覆盖了细到粗聚合，未覆盖粗到细。建议使用守恒的面积分配路径，并同时核查 CRS 变换中的人口守恒。

### C2．P1：conc_cf 初次运行没有对齐到暴露模板

位置：R/ingest.R：245–249。

conc_real 和 pop_total 共用 out$template，conc_cf 却使用传入的 template。第一次调用该值为 NULL，于是 conc_cf 根据自身 extent 建网格。

探针的暴露 extent 为 0 到 2，反事实 extent 为 0.25 到 2.25，分辨率同为 1。两者空间范围大量重叠，但坐标键交集为 0。该例说明不是重新投影到同一格网；实际计算可能空结果或丢格。

建议反事实始终对齐已确定的分析模板；测试既要检查分辨率，也要检查 extent、origin 和坐标键。

### C3．P1：域名自动改名没有同步 mort_lvl

位置：R/ingest.R：96–118；R/prepare-inputs.R：501；R/mortality.R：965–970。

把 calc_fild、年龄结构和死亡率中的 location 改成受支持的 Country，并传 mort_lvl＝Country。映射把这些列变成 location，参数却仍为 Country，因而误入全域退路。

同一个零风险反事实，规范列路径总量为 0，Country 别名路径总量为 1.875。多国家时还会错误地合并校准域。

建议保存实际列到规范列的映射，并同步参数语义，或者保留显式命名的校准域列。不能让自动映射悄悄切换计算分支。

### C4．P1：缺域退路忽略 conc_cf

位置：R/mortality.R：919–936。

.attributable_one_field 不接 conc_cf，返回 mort_base×（1−1／PWRR）。根据 AGENTS 的“mort_lvl 决定校准域、conc_cf 决定风险项”，此退路不应忽略风险输入。

同一份最小输入，RR 为 1 的反事实在正常域校准路径得到 0，缺域退路仍得到 1.875。现有指纹固定了退路的旧公式，所以指纹通过不能证明其符合顶层契约。

这是既有数值行为与顶层约定的冲突。若修复，必须先确认退路语义，并同步测试、NEWS 和指纹；本次没有擅自改动。

### C5．P1：分解状态直接按行相减，缺格时回收向量

位置：R/decompose.R：226–243。

基线两格的 Start 分别为 0.375、1.5；to 组人口表只保留第二格。第二格最终死亡数为 1.3333333333，结果却把同一 End 写到第一格和第二格。第一格得到虚假的 PG＝0.9583333333。

原因是 long_of 仅取矩阵数值，build 用向量相减和 bind_cols，没有先按坐标及 Cause_Age 对齐。长度为 1 的状态值被回收。长度不能整除时也可能直接报错。

建议给每个状态定义一致键空间，并明确缺格是报错、NA 还是其他策略，再按键做差分。不能以望远镜恒等式测试替代键对齐测试，因为错位向量也会满足望远镜加和。

### C6．P1：补充细一级域标签时优先连接粗域

位置：R/aggregate.R：613–637。

网格结果已有 location，补充的 calc_fild 同时有 x、y、location 和 province。代码优先按 shared domain 连接，只有没有共同域列才用坐标。

两格原值 0.375、1.5，各自属于 P0、P1，预期省总量分别为 0.375、1.5；实际两个省均为 1.875。国家列上的多对多连接复制了整国格子。

建议两侧有完整坐标键时优先以坐标连接，检查骨架键唯一性；只有无坐标时才考虑域级广播。

### C7．P1：区间链丢格后没有按键对齐

位置：R/uncertainty.R：48–65；R/mortality.R：492–506。

.range_sum 直接对各链的 .total 向量做 pmin／pmax，并未使用键对齐。50％浓度扰动使第一格浓度落到查表缺口后，扰动链只剩第二格；该单值被回收到第一格。

最小例中第一格中心估计为 0.375，CI_UP 被写成第二格的 1.5。代码还会使域标签与其他链的数值错配。

查表缺失如何处理应显式决定；无论采用何种策略，都不能把别格值复制过来。建议先对齐完整键空间，再逐格选区间端点，最后按域求和。

### C8．P2：validate＝off 不是完整静默模式

位置：R/mortality.R：434；R/ingest.R；R/utils.R；R/decompose.R：258–263。

仅关闭部分校验和 grain 输出。最小规范输入、mort_lvl＝NULL、validate＝off，仍收到 1 条分支 message。场景回退、列映射、分辨率、行政区以及分解 cat 也可能继续输出。

建议将“关闭校验”与“是否通知”语义集中处理，并用消息、警告和 stdout 三类捕获分别测试。不能用外部 suppressMessages 掩盖契约不一致。

## 🔍 约定本身的歧义与文档偏差

- 根 AGENTS 的 M 已经除以 1e5，紧接着的逐格式又除一次，按字面产生重复单位换算。正常计算核只除一次。本次以死亡率“每 10 万”契约和手算作为锚点，不把这个文档笔误实现进代码。
- “同域人均归因死亡率相同”并非普遍成立。公式含 RR（conc_cf），只有反事实风险在域内恒定时才相同。现有相关测试正是使用平坦 conc_cf。
- R/AGENTS 说缺 calc_fild 必须有栅格；当前实现与测试已支持具有坐标的表格自动生成骨架。应同步文档，不能在审查中自行删掉已实现行为。
- RDS 可以写出，但直接路径不能经 mortality 读取；测试明确使用 readRDS 后交回对象。属于 I/O 非对称和内部注释过宽，不据此夸大为已承诺的公开回读 API 故障。
- 显式 target_res 提前返回，未经过自动路径的 1e9 格护栏。细尺度流式引擎尚未实现，已在项目约定中列为已知缺口；不能声称当前支持全球 1 km。
- .INPUT_ROUTES 的测试只确认 handler 存在，不证明每一条 given／when／then 行为已被测试。
